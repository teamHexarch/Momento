## The five rules

1. **Clone, don't download.** A downloaded ZIP can't send your changes back. See guide 1.
2. **Sync before you start.** Always get everyone's latest changes first. See guide 2.
3. **One person per file at a time.** Say in the group chat what you're editing.
4. **Never upload `node_modules`.** It's thousands of installed files; `npm install` recreates it.
5. **Only real content.** No made-up people, quotes, logos, awards or numbers. See `CLAUDE.md`.
