# Hexarch website

The company website for Hexarch, the team behind Momento. Built with Next.js 16, Tailwind CSS 4 and Motion.

- **Live site:** https://hexarch-delta.vercel.app
- **New to the project? Start with the [team instructions](instructions/README.md).**

## Quick start

```
npm install
npm run dev
```

Then open http://localhost:3000. Full setup steps, including installing Node.js and Git, are in [instructions/01-setup.md](instructions/01-setup.md).

## Where things are

- `content/site.ts`: every word on the site (team, products, FAQ, emails)
- `app/`: the pages (home, products, Momento, about, investors, contact)
- `components/`: the sections, graphics and animations
- `public/team/`: team photos
- `CLAUDE.md`: design rules (Claude Code reads this automatically)
- `docs/hexarch-brief.md`: the project brief
- `instructions/`: how-to guides for the team
